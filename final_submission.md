# WordPress Web Design Assignment: NYUS Restaurant Landing Page

**Student Submission Report**

---

## 1. Project Overview
This assignment involved designing a professional, modern landing page for "NYUS", a Mediterranean restaurant in New York City, using WordPress. The design focuses on a clean, high-end aesthetic, utilizing a primary green brand color (#50E380) and immersive background imagery.

## 2. Content & Design Structure
The page is organized into three primary high-impact sections:

### Section 1: Hero Header
- **Heading:** A Really Good Place To Eat In The City Of New York
- **Subtext:** Professional marketing copy highlighting the NYC location.
- **CTA:** Primary "BOOK A TABLE NOW" button in brand green (#50E380).
- **Background:** High-resolution New York City streetscape with a dark overlay for text legibility.

### Section 2: Discover (Atmosphere)
- **Heading:** Discover The Good Atmosphere Of NYUS.
- **Design Layout:** A balanced grid layout featuring three themed sections: "Good Vibes", "Cozy Place", and "Relax Atmosphere".
- **Visuals:** Cohesive floral and natural imagery to emphasize the "exclusive haven of greenery".

### Section 3: Signature Menu
- **Heading:** Signature Menu
- **Layout:** Left-aligned content overlaying a dusk architectural scene with a reflecting pool.
- **CTA:** Secondary "BOOK A TABLE NOW" button.

---

## 3. WordPress Implementation Guide (Astra & Elementor)

### Step 1: Core Setup
1. **Theme:** Installed the **Astra** theme for its lightweight performance and customizable header/footer.
2. **Page Builder:** Used **Elementor** to create the custom section layouts and responsive grid.

### Step 2: Section Configuration Settings
- **Hero Section:**
  - **Height:** Set to `100vh` (Viewport Height).
  - **Background Overlay:** Classic Black (#000000) with an opacity of `0.5` to ensure the white text is readable.
  - **Button Styling:** Border Radius set to `25px`, Background Color set to `#50E380`.
- **Discover Grid:**
  - **Column Gap:** Set to "Extended" to provide ample whitespace between the high-resolution images.
  - **Typography:** Used the 'Montserrat' Google font family for all headings to maintain a modern feel.
- **Signature Menu:**
  - **Content Alignment:** Set to "Middle Left" within the Elementor Container settings.
  - **Background Size:** Set to "Cover" and "Fixed" (Parallax Effect) for added depth.
